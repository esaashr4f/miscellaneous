Languages

Languages you are learning, first choice first When a video has several subtitle tracks, Langtitles uses the first of these it finds. Codes: ja Japanese, ko Korean, zh Chinese, th Thai, vi Vietnamese, id Indonesian, hi Hindi, es, fr, de, it, pt, ru…

Subtitle sites

When a site has no subtitles in the language you are learning, Langtitles can fetch them from subtitle sites for the episode you are watching. Each site needs a free account. Set up any of them; Langtitles searches all that are set up.
